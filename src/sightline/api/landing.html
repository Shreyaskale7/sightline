How it works

Evidence, not vibes.

Four stages, each one measured before it shipped. A question never becomes an answer without surviving all of them.

Routeclassify the question's shape
→
Retrievefiltered search, fan-out per company/filing
→
Answergrounded on retrieved pages only
→
Verifyuncited claims don't ship
🖼️

Citations you can look at

Every claim links to the page image it came from — rendered inline. You never have to trust “see page 51”; page 51 is right there.

🛡️

Honest by design

A deterministic verifier strips fabricated citations and forces “I don't know” on unsupported answers. It refused 4 of 5 deliberately impossible questions in evaluation.

👁️

Visual-first retrieval

Financial pages are tables, footnotes, charts — layout that OCR destroys. Sightline embeds page images with a late-interaction retriever, so structure survives.

Measured, not marketed

Every number below is real.

A 38-question hand-verified benchmark grades every change. Improvements that don't move the numbers get benched — two popular techniques already were.
